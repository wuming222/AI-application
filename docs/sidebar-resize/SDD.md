# 侧边栏宽度可调整 - SDD

## 需求
当前侧边栏宽度固定为 260px，用户无法根据实际需要调整其宽度。需要在侧边栏右侧边缘添加可拖动的调整手柄，用户可以左右拖动来改变侧边栏的宽度，并将用户偏好保存到 localStorage，下次打开时保持自定义宽度。

## 实现步骤

### 1. 修改 Sidebar 组件
- 文件：`packages/web/src/components/Sidebar.tsx`
- 在侧边栏容器右侧添加一个拖动手柄 div（宽度 4-6px）
- 添加状态管理当前宽度（默认 260px）
- 从 localStorage 读取保存的宽度
- 监听鼠标事件：mousedown 开始拖动、mousemove 调整宽度、mouseup 结束拖动
- 限制最小宽度 200px、最大宽度 500px
- 拖动结束后保存宽度到 localStorage

### 2. 添加样式
- 文件：`packages/web/src/components/Sidebar.css`
- 拖动手柄样式：绝对定位在右侧，hover 时显示高亮
- 拖动时光标变为 `col-resize`
- 可选：拖动时显示半透明遮罩或高亮边框

### 3. 测试交互
- 验证可以左右拖动调整宽度
- 验证最小/最大宽度限制生效
- 验证刷新页面后保持自定义宽度
- 验证折叠状态下不显示拖动手柄

## 验收标准
- [ ] 侧边栏右侧有可见的拖动手柄区域
- [ ] 可以左右拖动调整侧边栏宽度
- [ ] 宽度限制在 200px-500px 范围内
- [ ] 拖动时有视觉反馈（光标变化、手柄高亮）
- [ ] 刷新页面后保持自定义宽度
- [ ] 折叠状态下不影响功能
