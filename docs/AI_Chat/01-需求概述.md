# AI 对话 UI 优化需求

## 背景
当前对话流程中，AI 的推理过程（reasoning）在数据层被采集但未在 UI 展示。用户只能看到"第 X 轮思考中..."的提示，无法实时了解 AI 的推理逻辑。

## 核心问题
- **数据流已打通**：`runAgentLoop.ts` 收集 reasoning 文本到 `step.reasoningText`
- **UI 层刻意隐藏**：`AgentProgress.tsx` 明确注释"模型思考过程全程不展示（用户决策）"
- **工具调用可见**：tool-call 状态会显示执行的工具列表和状态

## 待讨论的设计选择

### 选项 1：保持现状
- 优点：UI 简洁，避免暴露内部实现细节
- 缺点：用户等待时缺乏透明度

### 选项 2：流式显示思考内容
- 优点：提升透明度，增强信任感
- 缺点：可能显得冗长，与之前的用户决策冲突

### 选项 3：折中方案
- 默认折叠思考内容，提供展开按钮
- 或只在特定场景显示（复杂任务、多轮工具调用时）
- 或对思考内容进行精简/格式化后再展示

## 决策记录（2026-09-14）

### 最终方案：仅首轮显示推理内容
- **选择**：选项 3 的变体 - 只在第一轮（round === 1）流式显示 reasoningText
- **理由**：
  - 首轮推理通常包含对用户需求的核心理解和任务拆解，对用户最有价值
  - 后续轮次多为工具执行后的细节调整，信息密度低，展示意义不大
  - 平衡了透明度和 UI 简洁性
- **样式**：蓝色左边框 + 12px 缩进，与"思考中..."提示视觉分离

### 实现细节
- 修改文件：`packages/web/src/components/AgentProgress.tsx`
- 判断条件：`step.round === 1 && step.reasoningText`
- 不影响数据层：reasoningText 在所有轮次仍然采集，只是 UI 层选择性渲染

## UI 美化需求（2026-09-14 新增）

### 问题描述
当前 AgentProgress 组件的推理内容展示较为简陋，需要优化整体视觉效果，使其更符合现代对话 UI 的设计规范。

### 设计目标
1. **层次感**：通过颜色、间距、边框等视觉元素区分不同状态（thinking / tool-call / done）
2. **可读性**：推理内容作为核心信息，需要突出显示但不喧宾夺主
3. **一致性**：与现有消息气泡（MessageList）的视觉风格保持统一

### 具体样式需求

#### 1. 容器层级优化
- **外层容器**：
  - 背景色从 `#f0f0f0` 调整为更柔和的渐变色或半透明效果
  - 增加轻微阴影（box-shadow）提升立体感
  - 圆角从 12px 增加到 16px，与消息气泡保持一致

- **每轮步骤间距**：
  - 当前 `marginBottom: 4` 过于紧凑，调整为 8-12px
  - 最后一轮不添加底部间距

#### 2. 推理内容样式增强
- **文本区域**：
  - 背景色：使用浅蓝色渐变（如 `linear-gradient(135deg, #f0f7ff 0%, #e8f4ff 100%)`）
  - 内边距：从 0 增加到 `8px 12px`
  - 圆角：添加 6px 圆角，形成独立卡片感
  - 字体：行高从 1.6 调整为 1.7，字重保持正常但字号可从 13px 微调到 13.5px
  - 动画：添加淡入效果（fade-in），时长 200ms

- **左侧边框**：
  - 宽度从 3px 增加到 4px
  - 颜色从纯蓝 `#007bff` 调整为品牌色渐变或更柔和的蓝色 `#4a9eff`
  - 可选：添加轻微的发光效果（box-shadow）

#### 3. 状态标识优化
- **"思考中..."提示**：
  - 添加加载动画图标（旋转的 spinner 或脉冲点）
  - 文字颜色从 `#666` 调整为稍深的 `#555`，提升对比度
  - 可选：添加省略号动画（... → .. → . → ...）

- **工具调用状态**：
  - 图标尺寸适当放大（从默认增加到 14-15px）
  - 不同状态的配色优化：
    - running: `#d68910` → `#f39c12`（更明亮的橙色）
    - done: `#28a745` → `#2ecc71`（更清新的绿色）
  - 工具名称加粗（fontWeight: 500）

- **完成状态**：
  - "✓"符号改为更现代的勾选图标
  - 颜色从灰色调整为绿色系，传达成功感

#### 4. 响应式适配
- 在小屏幕设备上（< 768px）：
  - maxWidth 从 75% 调整为 85%
  - padding 适当缩小

#### 5. 过渡动画
- 新步骤出现时添加滑入动画（slide-in from bottom）
- 推理内容更新时使用平滑过渡（transition: all 0.2s ease）

### 参考设计
可参考以下产品的 AI 对话 UI：
- Claude 的思考过程展示（折叠/展开模式）
- ChatGPT 的工具调用状态指示
- GitHub Copilot Chat 的进度反馈

### 验收标准
1. 推理内容清晰可读，不会与工具调用信息混淆
2. 整体视觉风格与消息列表协调统一
3. 动画流畅不卡顿，不影响性能
4. 在不同浏览器下表现一致

### 相关文件
- `packages/web/src/components/AgentProgress.tsx` - 主要修改目标
- `packages/web/src/index.css` 或 `App.css` - 如需添加全局动画定义

## 待办需求：Markdown 渲染支持

### 问题描述
当前对话内容使用 `whiteSpace: 'pre-wrap'` 以纯文本形式显示，不支持 Markdown 语法（如加粗、列表、代码块、链接等）。

### 设计目标
- 支持常见 Markdown 语法：标题、加粗、斜体、列表、代码块、链接、表格
- 保持流式输出的兼容性
- 代码高亮支持（可选）

### 技术方案
- 引入轻量级 Markdown 解析库（如 `react-markdown`）
- 修改 `MessageList.tsx` 中的消息渲染逻辑
- 注意 XSS 防护和安全过滤
