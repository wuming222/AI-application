# AI 对话 UI 优化设计方案

## 日期
2026-09-14

## 整体风格
**温暖亲和风**（类似 Notion/Airbnb）

---

## 颜色体系

### 品牌色
- **主色**：`#6b9fd4`（低饱和蓝，用于用户消息、链接、强调元素）
- **辅助背景色**：`#ebebc8`（米黄色，用于页面背景或卡片背景）

### 功能色
- **成功**：AntD 默认绿色
- **错误**：AntD 默认红色 `#ff4d4f`
- **警告**：`#f39c12`（橙色，用于工具 running 状态）
- **信息**：AntD 默认蓝色

### 消息气泡
- **用户消息**：背景 `#6b9fd4`，文字白色，圆角 18px，轻微阴影
- **AI 回复**：背景 `#ffffff`（纯白），无边框，圆角 18px
- **工具调用组**：背景白色卡片，无边框，保持 emoji 图标

---

## 布局与间距

### 页面结构
```
┌─────────────────────────────────────┐
│   Header: "AI App Generator"        │  padding: 12px 16px, borderBottom: 1px solid #eee
├─────────────────────────────────────┤
│                                     │
│   MessageList                       │  padding: 0 20px, gap: 12px
│   (maxWidth: min(75%, 800px))       │
│                                     │
├─────────────────────────────────────┤
│   ChatInterface (输入区域)           │  borderTop: 1px solid #eee
└─────────────────────────────────────┘
```

### 间距规范
- **MessageList 左右边距**：20px
- **消息垂直间距**：12px
- **消息气泡最大宽度**：`min(75%, 800px)`

---

## 字体系统
保持 AntD 5 默认配置：
- **正文字号**：14px
- **行高**：默认
- **字重**：默认

---

## 组件设计

### 1. 输入区域（ChatInterface）

#### 容器样式
- **背景色**：`#f5f5f5`（保持现状）
- **圆角**：18px（从 24px 调整）
- **阴影**：添加轻微阴影 `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06)`
- **内边距**：保持现状

#### TextArea
- **类型**：多行输入（自适应高度，最小一行）
- **字号**：14px（保持现状）
- **边框**：无边框（嵌入容器中）
- **背景**：透明

#### 按钮布局
```
┌─────────────────────────────────────┐
│                                     │
│     TextArea（自适应高度）           │
│                                     │
├─────────────────────────────────────┤
│ [📎]                      [🎤] [↑] │
└─────────────────────────────────────┘
```
- **左侧**：📎 附件按钮（透明背景圆形）
- **右侧**：🎤 语音 + ↑ 发送（之间有间距）
- **发送按钮**：文字箭头 `↑`，背景 `#1a73e8` 蓝色圆形，圆角 20px

#### 图片预览
- 保持现状（60x60 缩略图，右上角关闭按钮）

---

### 2. 消息列表（MessageList）

#### 用户消息气泡
- **背景**：`#6b9fd4`
- **文字**：白色
- **圆角**：18px
- **阴影**：`box-shadow: 0 2px 6px rgba(107, 159, 212, 0.2)`
- **对齐**：右对齐（alignSelf: 'flex-end'）
- **最大宽度**：`min(75%, 800px)`

#### AI 回复气泡
- **背景**：`#ffffff`（纯白）
- **文字**：深色（`#333`）
- **圆角**：18px
- **阴影**：`box-shadow: 0 2px 6px rgba(0, 0, 0, 0.06)`
- **对齐**：左对齐（alignSelf: 'flex-start'）
- **最大宽度**：`min(75%, 800px)`

#### 工具调用组
- **背景**：白色卡片
- **边框**：无
- **图标**：保持 emoji
- **嵌套 details/summary**：保持现状

---

### 3. 进度指示（AgentProgress）

#### 容器样式（已完成）
- **背景**：渐变灰 `linear-gradient(135deg, rgba(240, 240, 240, 0.95) 0%, rgba(245, 245, 245, 0.9) 100%)`
- **阴影**：`0 2px 8px rgba(0, 0, 0, 0.08)`
- **圆角**：16px
- **文字颜色**：`#555`

#### 推理内容（已完成）
- **背景**：渐变蓝 `linear-gradient(135deg, #f0f7ff 0%, #e8f4ff 100%)`
- **左边框**：4px solid `#4a9eff`
- **圆角**：6px
- **内边距**：8px 12px
- **动画**：fadeIn 0.2s

#### Spinner（已完成）
- 旋转加载图标，0.8s 线性无限循环

---

### 4. Header

- **文案**：新建会话显示 "AI App Generator"，已有会话显示会话摘要
- **样式**：保持现状（padding: 12px 16px, borderBottom: 1px solid #eee, fontWeight: 600）

---

### 5. Sidebar（会话列表）

#### 整体设计
- **宽度**：260px（展开）/ 48px（折叠）
- **背景色**：`#fafafa`
- **边框**：右侧 `1px solid #f0f0f0`

#### Header
- **标题**："会话列表"，字号 15px，字重 600
- **按钮**：新建会话（PlusOutlined）、收起侧边栏（MenuFoldOutlined）
- **样式**：AntD Button type="text"

#### 会话列表
- **布局**：卡片式设计，每个会话项独立圆角卡片
- **激活状态**：白色背景 `#ffffff`，细边框 `1px solid #e8e8e8`，轻微阴影
- **非激活状态**：透明背景，无边框
- **圆角**：8px
- **间距**：每项之间 marginBottom 4px

#### 会话项内容
- **图标**：MessageOutlined（蓝色 `#6b9fd4`）
- **标题**：截断省略，激活时加粗（fontWeight: 500），颜色 `#333` / `#666`
- **操作菜单**：Dropdown（MoreOutlined 触发）
  - 重命名（EditOutlined）
  - 删除（DeleteOutlined，danger 红色）

#### 空状态
- 使用 AntD Empty 组件（PRESENTED_IMAGE_SIMPLE）

#### 折叠状态
- 仅显示两个按钮：展开（MenuUnfoldOutlined）、新建（PlusOutlined）
- 垂直居中排列

---

## 动画与过渡（按 AntD 默认）

### 已添加的自定义动画
- **spin**：spinner 旋转（0.8s linear infinite）
- **fadeIn**：推理内容淡入（0.2s ease-in）
- **slideInBottom**：新步骤滑入（0.3s ease-out）

### AntD 自带动画
- 按钮点击反馈
- 消息提示出现/消失
- 组件展开/收起

---

## 特殊状态设计（按 AntD 默认）

### 空状态
- 当前：居中灰色文字"发送一条消息开始对话"
- 可选增强：使用 AntD `<Empty>` 组件（带插图）

### 加载中状态
- 当前：AgentProgress 组件
- 保持不变

### 错误状态
- 使用 AntD `<Message.error>` 显示错误提示
- 提供重试机制

### 网络断开
- 使用 AntD `<Alert>` 顶部提示条

---

## 响应式设计（按 AntD 默认）

### 断点
- Desktop: > 1024px
- Tablet: 768px - 1024px
- Mobile: < 768px

### 适配规则
- **消息气泡 maxWidth**：Desktop/Tablet 75%，Mobile 85%
- **输入框**：移动端增加触摸目标尺寸
- **按钮**：移动端适当放大

---

## 深色模式（AntD 自动跟随系统）

使用 AntD 5 的 `theme.algorithm.dark`，自动根据 `prefers-color-scheme` 切换。

## 实施计划

### Phase 1: 引入 AntD 5
1. 安装依赖：`antd @ant-design/icons`
2. 配置 ConfigProvider（主题、深色模式）
3. 创建全局样式文件

### Phase 2: 替换输入区域组件
1. Input → Input.TextArea
2. 原生 button → Button
3. 文件上传 → Upload
4. 调整布局为多行输入 + 底部按钮

### Phase 3: 优化消息气泡样式
1. 用户消息：背景 `#6b9fd4`，圆角 18px，阴影
2. AI 消息：背景 `#ffffff`，圆角 18px，阴影
3. 调整 MessageList 左右边距为 20px
4. 添加最大宽度限制 800px

### Phase 4: 完善细节
1. 添加错误提示（Message.error）
2. 优化空状态（可选 Empty 组件）
3. 测试深色模式
4. 测试响应式布局

---

## 验收标准

1. 整体视觉风格符合温暖亲和定位
2. 消息气泡样式统一，圆角 18px，有层次感
3. 输入区域改为多行输入，按钮布局合理
4. AntD 组件与自定义组件风格协调
5. 深色模式正常工作
6. 响应式布局在不同屏幕下表现良好
7. 动画流畅，不影响性能
